# LCM update packages

These zips are **program updates only**. They do not contain shop data.

## Current package

**[Download latest: lcm-update-20260813-132024.zip](https://github.com/Jsteck123/lcm-updates/raw/main/lcm-update-20260813-132024.zip)**

Same file, stable name: **[lcm-update-latest.zip](https://github.com/Jsteck123/lcm-updates/raw/main/lcm-update-latest.zip)**

This package restores the EMJ material calculator, Settings price book, and quote estimate.

## Install on the office PC

1. Click the download link above. Save the zip (do not unzip it).
2. Open LCM → **Settings → Update app…**
3. Choose that `lcm-update-*.zip` file.
4. Restart LCM on the host PC, then refresh phones and other computers.

Your quotes, inventory, orders, and drawings stay on the host. The zip only replaces program files.
